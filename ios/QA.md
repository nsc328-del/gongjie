# 原生版验证记录 · 2026-09-12

## 本次验证

本轮将当前 Web 的状态、认知、地点与时间契约同步到独立 SwiftUI App。离线流程使用可控制的模型替身，存储、上下文编译、领域校验和引擎均运行真实 Swift 实现。

- 完整旅程：创建世界、首次入场、重复进入不生成重复开场、玩家消息立即保存、正文完成后结算、固定预告时间推进、新时段再次相遇、重启恢复历史。
- 信息边界：私密纸条只向能看见的人投影；角色后续规划、正文、裁判、核对均不含旁人没看见的口令。个人现场不回流为公共房间状态；误解保留所信版本，不补上客观时间、地点与详情。
- 地点：提及、确认与到达分开；已有地点不重复准入，新地点必须通过规划及正文核对；别名知情不授予隐藏描述或完整路线；失败不发布正文或产生地图副作用。
- 结算：提案修复不重新生成已核对正文；准备好的补丁不重复调用模型；语义拒绝终结原轮，提供方故障保留队列；同场其他人可继续回应，重启后按原顺序恢复且不重复修改关系。
- 存储与创作：存档只列当前世界，读档原子恢复并先自动备份；动态地点、认知、在场、玩家卡与草稿随故事保存；导入重建对话及消息引用；旧原生记录迁移；修改创作底稿不覆盖当前时间、位置和关系进展，也不把游玩进度写成重置底稿。
- 协议：SSE 中文分片、CRLF、完成标记、取消与中断、用量累计；达到长度上限的响应不能当成完整正文或裁判结果。

`swift test`：通过，真实模型用例因未提供本轮测试凭据跳过。

`xcodebuild`：通用 iOS Simulator Debug 和通用 iOS 真机 Release 编译均通过，关闭签名。只有无 AppIntents 依赖时跳过元数据提取的工具提示。

`python3 ios/scripts/sync-worldbook.py --check`：通过，内置《白昼将死》和 16 项提示词与当前 Web 源文件一致。

## 界面核对范围

已接入原生存读档、玩家卡、四名角色的头像与立绘、世界介绍、时间预告和赴约入口；对话页不显示预告。生成与结算阶段分开，已完成的正文退出流式状态，无硬变化不显示变化回执，拒绝回执不展示内部错误码。已离开现场时禁用发送并提供明确的返回入口。

后台预告在进入、发送、编辑和读档前取消并等待结束，避免占用世界；草稿与流式检查点不使时间预告反复失效。读档后清理旧界面草稿缓存。

本轮没有启动 Xcode Preview、模拟器界面或真机 App。键盘、横屏、VoiceOver、超大动态字体、文件选择器、AirDrop、实际后台限时和设备安装仍需真机验证，编译结果不代表这些交互已实测。

## 真实模型验证边界

2026-09-08 的上一版曾用原生 URLSession 完成 DeepSeek 入场、对话、结算和推进闭环。本轮没有重新调用线上 DeepSeek，不把旧测试作为新地点及观察流程的真实模型通过证明。当前提供方仍可能返回格式错误、超时或不可靠叙事；本轮验证的是这些情况下的处理和信息隔离。
