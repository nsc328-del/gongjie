# 跨时段故事体验检查 · 2026-09-07

使用独立 SQLite 世界和当前配置的 deepseek-v4-flash 测试。没有修改正式世界的对话、事实或模型设置。实际模型结果与固定断言的回归测试分别记录，不把模拟回复当成模型质量证据。

## 故事链结果

| 环节 | 实际观察 |
| --- | --- |
| 初遇沈砚 | 开场生成后校对并保存，重复进入不重复写入 |
| 私密告知与承诺 | 私人暗号只进入沈砚认知；“明天清晨回公馆”进入待履行列表 |
| 初遇林照并试探 | 林照回答“我不知道你的私人暗号，也没人告诉过我”；询问明天能否来没有变成玩家承诺 |
| 推进到次日清晨 | 沈砚因承诺形成等待意图；林照与岑野保持安静；不再给不在场的人提供玩家实时位置和痕迹 |
| 再见沈砚 | 保留稳定人格与称谓，生成一条接续开场，历史标出再次相遇 |
| 明确赴约 | 承诺列表清空，秘密仍只留在原知情者，世界公开事件没有混入私密内容 |
| 清晨首次遇见岑野 | 使用当前清晨，不再重演最初的夜晚开场 |

整条真实模型链结束后：世界时间为次日清晨，待结算任务为 0，待履行承诺为 0，林照对暗号的认知为 0。之后对“删除失效等待线”和“校对世界播报”分别使用同一轮原文与原始输入复测通过。

## 发现与修正

- 接续开场原本遗漏人格、说话方式、欲望指纹等；现已携带完整底色及称谓，首次开场也经过记忆校对。
- 迟到的首次相遇原本重新使用最初开场；现在依据当前时段与本人有效牵引。
- 世界脉搏原本把玩家当前位置、外部痕迹传给所有角色；现在按同地观察范围投影，私人承诺不进入公开播报。
- 玩家自身状态中混入与上一人物的距离，可能污染下一现场；人物相关软状态不作为可携带身体观察注入其他现场，提取指令也明确分开两者。
- 未改变的承诺原本每轮删除重建；现在保留记录身份，兑现或取消才删除，并核对相应等待线是否已失效。
- 裁判原本混用旧对话证据、对象形态承诺和当前未变化的字段；现在单列本轮原文，输入承诺为文字数组，只核对实际变化所需证据，失败重提携带具体问题。
- 世界推进原本可提交空时间或相同时间；现在拒绝无效锚点，整个事务不产生变化。
- 过夜播报曾捏造玩家整夜在某地及由此产生的痕迹；现在只保留或淡去已有玩家状态，发布前另行校对播报，删除无来源的到访和“无人经过”等全知断言。
- 跨地点人物曾被标为“就在眼前”；现在要求角色与玩家位置相符。

## 等待时间

初始测试中，一次结算请求约 197 秒后仍无正文。另一次诊断明确返回 length，输出预算用于思考而未产生正文。DeepSeek V4 默认启用 high 思考，依据其[官方参数文档](https://api-docs.deepseek.com/guides/thinking_mode/)调整：叙事与提取直接输出，独立语义核对和记忆校对使用 low 思考。

修正后的完整样本中，叙事与提取通常约 2–6 秒；校对约 5–39 秒。直接输出的一次提取与核对组合曾约 7 秒，但最终保留了更审慎的 low 校对，不能把 7 秒当成所有回合的保证。

## 验证与边界

- 42 项本地检查通过，覆盖承诺生命周期、角色输入边界、时间推进原子性、有效证据、入场幂等、协议参数和已有恢复链路。
- 浏览器验证了承诺入口与历史相遇分隔，没有前端运行错误。
- 模型确实会产生无依据草稿，校对能拦下本次复现的问题，但自然语言核对仍由模型完成，不能保证所有题材与长历史都零幻觉。
- 自然语言时间的真正先后由模型结合目标时段判断；确定性校验保证非空、非现实钟点且不同于当前值，不等于完整的故事日历。
- 本阶段没有引入自动赴约、自动替玩家行动或角色互相聊天的新规则。
